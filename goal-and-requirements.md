# Anh & Quýt — Personal Love Website

One-line tagline: Một website tình yêu dành riêng cho "Quýt" — thuần HTML & CSS, host trên GitHub Pages.

## Overview

Một website tình cảm single-page dành tặng cho bạn gái "Quýt", kể bằng lời yêu, ảnh kỷ niệm, hiệu ứng trái tim bay và bộ đếm ngày kỷ niệm.

## Problem

Muốn thể hiện tình yêu theo một cách cá nhân và đáng nhớ, thay vì lời yêu hoặc tin nhắn thông thường.

## Capabilities

- Hiển thị lời yêu (love letter) được cá nhân hóa với tên "Quýt".
- Hiển thị ảnh kỷ niệm do người dùng tự upload.
- Hiệu ứng trái tim bay bằng CSS.
- Đếm ngược ngày kỷ niệm.

## Tech Notes

- HTML + CSS thuần, không dùng JavaScript.
- Host trên GitHub Pages.
- Phong cách: soft pastel + floating hearts (animation CSS thuần qua ký tự ♥ + keyframes); file: `index.html`, `style.css`, `assets/`.

## Alternatives Considered

- **madeforjenny** — Love letter + gallery với animated envelope; gap: nặng JavaScript, không hợp constraint “chỉ HTML/CSS”.
- **akakadir/lovescript** — Love letter tương tác có text typing; gap: dùng JavaScript.
- **Chychyndr/i-love-you** — Trang static tối giản + heart animation; gap: chưa có letter/gallery/countdown.
